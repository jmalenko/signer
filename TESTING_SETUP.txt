HOW TO RUN TESTS:

Option 1: Basic Tests (No LibreOffice Required)
  pytest tests/

Option 2: With Command-Line Parameter
  pytest tests/ --libreoffice-path "C:\Users\jaro\PortableApps\LibreOfficePortable\App\libreoffice\program\soffice.exe"

Option 3: Configure in Settings (Persistent)
  Add to C:\Users\jaro\AppData\Roaming\Signer\config.json:
    "libreOffice_path": "C:\\Users\\jaro\\PortableApps\\LibreOfficePortable\\App\\libreoffice\\program\\soffice.exe"
  Then run: pytest tests/
